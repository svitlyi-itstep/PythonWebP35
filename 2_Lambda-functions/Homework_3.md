## Лямбда-функції

### 1. Нормалізація рядків

Використовуючи функцію `map()` та лямбда-функцію, зробити так, щоб список рядків нормалізувався: рядки в ньому мають переходити у нижній регістр та прибиратися зайві пробіли.

Приклад:
```python
["  hello ", "WORLD", " PyThOn  "]
# має перетворитися на 
["hello", "world", "python"]
```

### 2. Складний запит

Є список студентів:
```python
users = [
    {"name": "Іван", "age": 25},
    {"name": "Оля", "age": 17},
    {"name": "Петро", "age": 30}
]
```

Отримати список **імен повнолітніх у верхньому регістрі, відсортованих за довжиною**.

Використати тільки `filter`, `map`, `sorted`, `lambda`.
