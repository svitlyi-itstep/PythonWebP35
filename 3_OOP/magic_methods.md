
# Магічні методи Python (magic/dunder methods)

> **Магічні методи (або dunder-методи, від double underscore) у Python** — це спеціальні методи з подвійним підкресленням (наприклад, __init__, __str__), які автоматично викликаються інтерпретатором під час виконання певних операцій (створення об'єкта, додавання, виведення тексту тощо). Вони дозволяють налаштовувати поведінку власних класів.

Перелік всіх магічних методів можна знайти тут: https://www.pythonmorsels.com/every-dunder-method/
