# Розробка вебдодатків з використанням Python

## ЗАВДАННЯ НА ФІНАЛЬНИЙ ПРОЄКТ

Розробити повноцінний вебдодаток для роботи з певною предметною областю на власний вибір.

---

## Варіанти виконання

| ![Static Badge](https://img.shields.io/badge/Template--based_(MVT)-purple?style=for-the-badge) | ![Static Badge](https://img.shields.io/badge/Django%20REST%20API-red?style=for-the-badge)|
|---|---|
|  Django-додаток з рендером сторінок на сервері через шаблонізатор Django Templates | Django REST Framework (DRF) як бекенд + окремий фронтенд (HTML/JS або React) |

Обидва варіанти є рівноцінними. Варіант обирається студентом самостійно.

---

## Обов'язкові вимоги

### Моделі та база даних
- Додаток має працювати **мінімум з двома моделями даних**, пов'язаними між собою (наприклад: `Book` та `Review`, `Product` та `Order`, `Post` та `Comment`).
- Моделей може бути більше.
- Для зберігання даних використовується **база даних** (SQLite для розробки, за бажанням — PostgreSQL).
- Моделі описуються через `django.db.models.Model` та реєструються в `admin.py`.

### CRUD
Для кожної основної моделі реалізувати повний набір операцій:
- ![Static Badge](https://img.shields.io/badge/CREATE-green?style=flat) — створення запису
- ![Static Badge](https://img.shields.io/badge/READ-yellow?style=flat) — перегляд списку та деталей запису
- ![Static Badge](https://img.shields.io/badge/UPDATE-blue?style=flat) — редагування запису
- ![Static Badge](https://img.shields.io/badge/DELETE-red?style=flat) — видалення запису

### Складні запити (мінімум 2)
Реалізувати принаймні два з наведених варіантів:
- Фільтрація даних за одним або кількома полями
- Текстовий пошук (`icontains`, `Q`-об'єкти)
- Сортування результатів

### Фронтенд
- Використовувати **HTML-форми** або **JavaScript (Fetch API)** для взаємодії з даними.
- Інтерфейс має бути зрозумілим та охоплювати всі CRUD-операції.

## Додаткові можливості (підвищують оцінку)

- **Система користувачів** — реєстрація, вхід/вихід, розмежування доступу для звичайних користувачів та адміністраторів. → [Документація](https://docs.djangoproject.com/en/stable/topics/auth/)

- **Пагінація** — розбивка довгих списків на сторінки. → [Paginator (Django)](https://docs.djangoproject.com/en/stable/topics/pagination/) · [PageNumberPagination (DRF)](https://www.django-rest-framework.org/api-guide/pagination/#pagenumberpagination)

- **DTO / Serializers** — використання серіалайзерів DRF або форм Django для валідації та передачі даних. → [ModelForm](https://docs.djangoproject.com/en/stable/topics/forms/modelforms/) · [DRF Serializers](https://www.django-rest-framework.org/api-guide/serializers/)

- **Django Admin** — налаштований адмін-інтерфейс із пошуком, фільтрами та відображенням потрібних полів. → [Документація](https://docs.djangoproject.com/en/stable/ref/contrib/admin/)

- **Завантаження файлів / зображень** — поле `ImageField` або `FileField` у моделі. → [Документація](https://docs.djangoproject.com/en/stable/topics/files/)

- **Розгортання у Docker** — додаток упакований у контейнер через `Dockerfile` та `docker-compose.yml`, запускається командою `docker compose up`. → [Офіційна документація Docker](https://docs.docker.com/get-started/) · [Приклад Django + Docker](https://docs.docker.com/samples/django/)

## Формат здачі проєкту

Проєкт можна здати одним із двох способів:

### Git-репозиторій (GitHub / GitLab)
- Надати посилання на публічний репозиторій
- У репозиторії обов'язково має бути файл **`README.md`** з описом проєкту та інструкцією із запуску
- Додати скриншоти або відео роботи додатку (можна в `README.md` або окремою папкою `screenshots/`)

### Архів з проєктом
- Надати ZIP-архів із папкою проєкту
- Обов'язково включити файл **`README.md`** з описом та інструкцією із запуску
- Разом із архівом надати скриншоти або відео, що демонструють роботу додатку

> **Незалежно від способу здачі:** наявність `README.md` та скриншотів / відео є обов'язковою.

## Приклади тем для проєкту

### 1. 📚 Бібліотека / Книжковий каталог

**Короткий опис:** Сервіс для обліку книг, авторів та відгуків читачів.

**Моделі:** `Author`, `Book`, `Review`

**Структура сайту:**
- Головна — список книг із пошуком та фільтрацією за жанром і автором
- Сторінка книги — деталі, список відгуків, форма додавання відгуку
- Сторінка автора — біографія та книги автора
- Адмін / особистий кабінет — додавання та редагування книг

---

### 2. 🛒 Інтернет-магазин

**Короткий опис:** Каталог товарів із можливістю оформлення замовлень.

**Моделі:** `Category`, `Product`, `Order`, `OrderItem`

**Структура сайту:**
- Головна — популярні та нові товари
- Каталог — список товарів із фільтрацією за категорією та ціною
- Сторінка товару — опис, ціна, кнопка «Додати до кошика»
- Кошик / Оформлення замовлення
- Особистий кабінет — історія замовлень

---

### 3. 📰 Блог / Новинний портал

**Короткий опис:** Платформа для публікації статей із системою коментарів та тегів.

**Моделі:** `Post`, `Comment`, `Tag`

**Структура сайту:**
- Головна — стрічка останніх публікацій
- Сторінка статті — повний текст, коментарі, форма коментування
- Фільтрація за тегами та пошук по тексту
- Панель автора — створення та редагування власних статей

---

### 4. 🎬 Фільмотека / Серіали

**Короткий опис:** База фільмів та серіалів із рейтингами та рецензіями.

**Моделі:** `Movie`, `Genre`, `Review`

**Структура сайту:**
- Головна — топ-фільми та новинки
- Каталог — фільтрація за жанром, роком, рейтингом; пошук за назвою
- Сторінка фільму — опис, трейлер (посилання), рецензії
- Особистий кабінет — список «Хочу подивитись» / «Переглянуто»

---

### 5. 🏋️ Фітнес-трекер / Тренування

**Короткий опис:** Додаток для планування та відстеження тренувань.

**Моделі:** `Exercise`, `Workout`, `WorkoutExercise`

**Структура сайту:**
- Головна — останні тренування користувача та статистика
- Каталог вправ — список із фільтрацією за групою м'язів
- Створення тренування — вибір вправ, підходів та ваги
- Історія — перегляд минулих тренувань із прогресом

---

### 6. 🏨 Бронювання (готель / хостел / коворкінг)

**Короткий опис:** Система перегляду та бронювання кімнат або робочих місць.

**Моделі:** `Room`, `Booking`, `Review`

**Структура сайту:**
- Головна — пошук за датами та типом кімнати
- Каталог номерів — фільтрація за ціною та кількістю місць
- Сторінка номера — фото, опис, форма бронювання
- Особистий кабінет — активні та архівні бронювання

---

### 7. 📋 Дошка задач / To-Do менеджер

**Короткий опис:** Інструмент для керування проєктами та задачами у стилі Kanban.

**Моделі:** `Project`, `Task`, `Comment`

**Структура сайту:**
- Список проєктів користувача
- Дошка проєкту — задачі, згруповані за статусом (To Do / In Progress / Done)
- Сторінка задачі — опис, виконавець, дедлайн, коментарі
- Фільтрація задач за пріоритетом та дедлайном

---

### 8. 🎮 Каталог відеоігор / Ігровий трекер

**Короткий опис:** База відеоігор із можливістю вести особистий список пройдених та запланованих ігор, залишати оцінки та відгуки.

**Моделі:** `Game`, `Genre`, `Platform`, `UserGameEntry`, `Review`

**Структура сайту:**
- Головна — популярні ігри та нещодавно додані
- Каталог — пошук і фільтрація за жанром, платформою, роком виходу, рейтингом
- Сторінка гри — опис, скриншоти (посилання), середня оцінка, відгуки гравців
- Особистий кабінет — список ігор зі статусами (Граю / Пройдено / Заплановано / Кинуто), статистика

---

### 9. 🏆 Платформа для ігрових турнірів

**Короткий опис:** Сервіс для організації та відстеження кіберспортивних турнірів: реєстрація команд, жеребкування, таблиця результатів.

**Моделі:** `Tournament`, `Team`, `Player`, `Match`, `Result`

**Структура сайту:**
- Головна — активні та майбутні турніри
- Сторінка турніру — сітка матчів, учасники, результати
- Профіль команди — склад гравців, статистика виступів
- Адмін-панель — реєстрація команд, введення результатів матчів
- Фільтрація за грою, статусом турніру, датою

---

### 10. 🤖 AI-асистент із збереженням історії

**Короткий опис:** Чат-інтерфейс для спілкування з мовною моделлю (через OpenAI API або будь-який інший провайдер). Усі розмови зберігаються в базі даних, доступні для перегляду та повторного відкриття.

**Моделі:** `Conversation`, `Message`

**Структура сайту:**
- Головна / дашборд — список збережених розмов із датою та назвою
- Чат-сторінка — діалог із моделлю у реальному часі (через Fetch API або WebSocket)
- Сторінка розмови — перегляд та продовження збереженого діалогу
- Особистий кабінет — налаштування (обраний провайдер / модель, системний промпт)

---

### 11. 🧠 Платформа для створення та проходження тестів

**Короткий опис:** Додаток, де автори створюють тести з питаннями та варіантами відповідей, а користувачі проходять їх та бачать свої результати. Може використовуватись для навчання, квізів або AI-генерації питань.

**Моделі:** `Quiz`, `Question`, `Answer`, `Attempt`, `AttemptAnswer`

**Структура сайту:**
- Головна — публічні тести з пошуком і фільтрацією за темою
- Сторінка тесту — опис, кількість питань, кнопка «Почати»
- Проходження тесту — покрокове або на одній сторінці
- Результати — правильні відповіді, набрані бали, порівняння з іншими
- Кабінет автора — створення та редагування тестів, статистика проходжень
