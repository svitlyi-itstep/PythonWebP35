# Домашня робота №1

`Декоратори та генератори`

### 1. Декоратор логування

Зробити декоратор, який буде автоматично логувати виклик функції. Логування має відбуватися у консоль з виведенням поточного часу. 

Приклад використання:
```python
@logger
def helloworld():
    pass

helloworld() 
# Має вивести у консоль:
# [21:30] Викликано функцію helloworld

```

**Додатково:** зробити так, щоб логи виводились у файл.

### 2. Генератор chunk-ів (batch processing)

Реалізувати генератор, який розбиває iterable на чанки розміру n.

```python
for chunk in chunked([1,2,3,4,5], 2):
    print(chunk)
    # → [1,2], [3,4], [5]
```
