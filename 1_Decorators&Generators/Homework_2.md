## Декоратори та генератори (ч.2)

### 1. Декоратор для генератора

Розробити декоратор, який має додаватися до генератора та логувати кожне повернене генератором значення. Логування може відбуватися як у консоль, так і у файл.

Приклад використання:
```python
def generator_logger(...):
    # Реалізація декоратора

# Оголошення генератора
@generator_logger
def numbers(count):
    for i in range(count):
        yield i

# Використання генератора
for num in numbers(3):
    print(f"Received: {num}")

# Має вивести у консоль:
# [LOG] Yield: 0
# Received: 0
# [LOG] Yield: 1
# Received: 1
# [LOG] Yield: 2
# Received: 2

```
